🔤 ১. HTML Introduction

HTML Tag দিয়ে ওয়েবপেজের বিভিন্ন অংশ চিহ্নিত করা হয়। সাধারণত একটি Element-এ opening tag, content এবং closing tag থাকতে পারে।

<h1>আমার প্রথম ওয়েবপেজ</h1>

🧱 ২. HTML Document Structure

<!DOCTYPE html>
<html lang="bn">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>আমার ওয়েবপেজ</title>
</head>
<body>
    <h1>স্বাগতম</h1>
    <p>আমার প্রথম ওয়েবপেজ।</p>
</body>
</html>

📦 <div> — Block Container

<div> হলো একটি Generic Block-level Container, যা দিয়ে HTML-এর অন্যান্য Element-কে গ্রুপ করে Layout, Styling বা JavaScript-এর জন্য ব্যবহার করা হয়। এর নিজস্ব কোনো Semantic অর্থ নেই।

ব্যবহারTag উদাহরণ
সাধারণ Div<div>এখানে কনটেন্ট</div>
Class সহ Div<div class="box">কনটেন্ট</div>
ID সহ Div<div id="header">কনটেন্ট</div>
Inline Style সহ Div<div style="color:red">লাল লেখা</div>
একাধিক Class সহ Div<div class="card highlight">কনটেন্ট</div>
Nested (একটির ভিতরে আরেকটি) Div<div class="outer"><div class="inner">ভিতরের অংশ</div></div>
Data Attribute সহ Div<div data-id="101" data-role="card">কনটেন্ট</div>
Flexbox Container হিসেবে Div<div style="display:flex"><div>১</div><div>২</div></div>
Grid Container হিসেবে Div<div style="display:grid"><div>A</div><div>B</div></div>
Hidden Div<div hidden>এই কনটেন্ট দেখা যাবে না</div>
Title (Tooltip) সহ Div<div title="তথ্য">মাউস রাখুন</div>
Click Event সহ Div<div onclick="alert('ক্লিক হয়েছে')">ক্লিক করুন</div>
Editable Div (contenteditable)<div contenteditable="true">এখানে সম্পাদনা করুন</div>
Layout Container হিসেবে Div<div class="container"><header>...</header><main>...</main></div>

✍️ ৩. Headings & Paragraph

<h1> থেকে <h6> পর্যন্ত Heading এবং <p> দিয়ে Paragraph তৈরি করা হয়।

<h1>প্রধান শিরোনাম</h1>
<h2>উপশিরোনাম</h2>
<p>এটি একটি অনুচ্ছেদ।</p>

📄 <p>-এর সকল ট্যাগ ও ব্যবহার

ব্যবহারTag উদাহরণ
সাধারণ Paragraph<p>এটি একটি অনুচ্ছেদ।</p>
Class সহ Paragraph<p class="intro">পরিচিতিমূলক লেখা।</p>
ID সহ Paragraph<p id="main-text">মূল লেখা।</p>
Inline Style সহ<p style="color:green;font-size:18px">স্টাইল করা লেখা।</p>
Title (Tooltip) সহ<p title="অতিরিক্ত তথ্য">মাউস রাখুন এখানে।</p>
Text Alignment সহ (CSS দিয়ে)<p style="text-align:center">মাঝখানে লেখা।</p>
ভিতরে Formatting Tag সহ<p>এটি <strong>গুরুত্বপূর্ণ</strong> একটি লেখা।</p>
ভিতরে Link সহ<p>বিস্তারিত জানতে <a href="#">এখানে ক্লিক করুন</a>।</p>
Line Break সহ (একই Paragraph-এ)<p>প্রথম লাইন।<br>দ্বিতীয় লাইন।</p>
ভাষা নির্ধারণ (lang)<p lang="en">This is English text.</p>
লেখার দিক নির্ধারণ (dir)<p dir="rtl">ডান থেকে বামে লেখা।</p>
Hidden Paragraph<p hidden>এই লেখা দেখা যাবে না।</p>
Data Attribute সহ<p data-type="note">একটি নোট।</p>
একাধিক Class সহ<p class="text-lg bold-text">বড় ও মোটা লেখা।</p>
Editable Paragraph (contenteditable)<p contenteditable="true">এখানে সম্পাদনা করা যাবে।</p>

🔖 <span> — Inline Container

<span> হলো একটি Generic Inline Container, যা কোনো লেখার নির্দিষ্ট অংশকে Style, Highlight বা JavaScript দিয়ে নিয়ন্ত্রণ করতে ব্যবহার করা হয়। <div>-এর মতো এরও নিজস্ব কোনো Semantic অর্থ নেই, তবে এটি Block নয়, Inline Element।

ব্যবহারTag উদাহরণ
সাধারণ Spanএটি একটি <span>বিশেষ</span> শব্দ।
Class সহ Span<span class="highlight">গুরুত্বপূর্ণ</span>
ID সহ Span<span id="price">৫০০৳</span>
Inline Style সহ (Color)<span style="color:red">লাল লেখা</span>
Font Weight/Size সহ<span style="font-weight:bold;font-size:20px">বড় ও মোটা</span>
Background Highlight সহ<span style="background:yellow">হাইলাইট করা</span>
একাধিক Class সহ<span class="tag success">সম্পন্ন</span>
Nested Span<span>বাইরের <span style="color:blue">ভিতরের</span> অংশ</span>
Data Attribute সহ<span data-price="500">৫০০৳</span>
