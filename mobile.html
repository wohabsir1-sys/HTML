📝 ধাপ ১ — PRD প্রম্পট

নিচের প্রম্পটটি কপি করে ChatGPT বা Claude-এ পেস্ট করুন:

আমার একটা সিস্টেম-ওয়াইড অ্যান্ড্রয়েড ভয়েস টাইপিং অ্যাপ দরকার। যেটার মধ্যে Accessibility Service এবং Floating Overlay থাকবে—যাতে যেকোনো অ্যাপে ক্লিক করলে মেসেঞ্জার বাবলের মতো মাইক্রোফোন বাটন ভেসে ওঠে। ট্যাপ করে কথা বললে সেটা Groq Whisper API দিয়ে টেক্সটে কনভার্ট হবে এবং সরাসরি লেখার জায়গায় পেস্ট হয়ে যাবে। আমাকে Kotlin এবং Jetpack Compose আর্কিটেকচারে একটি পূর্ণাঙ্গ PRD লিখে দাও।

⚙️ ধাপ ২ — AI Studio-তে অ্যাপ বানানো

  1. aistudio.google.com এ যান।
  2. বাঁ পাশে “New app” ক্লিক করুন।
  3. “Build an Android app” সিলেক্ট করুন।
  4. প্রথম ধাপের PRD টেক্সট পেস্ট করে Enter চাপুন।
  5. এরর এলে চ্যাটবক্সে লিখুন: fix this error: [error text]
  6. চ্যাট অনেক লম্বা হয়ে গেলে “+ New chat” দিয়ে নতুন করে শুরু করতে পারেন।

📱 ধাপ ৩ — ফোনে সেটিংস

ইনস্টল করার আগে Developer Options চালু করুন:

  1. Settings → About Phone এ যান।
  2. Build Number-এ ৭ বার ট্যাপ করুন। কিছু ফোনে আগে PIN দিতে হতে পারে।
  3. Settings → System → Developer Options এ যান।
  4. USB Debugging চালু করুন।
৪

💻 ধাপ ৪ — ফোনে ইনস্টল

  1. USB ক্যাবল দিয়ে ফোন ও কম্পিউটার সংযুক্ত করুন।
  2. ফোনে “Allow USB Debugging?” পপআপ এলে কম্পিউটারটি বিশ্বাসযোগ্য হলে Allow করুন।
  3. AI Studio-তে Install → Install via USB নির্বাচন করুন।
  4. ফোনে ইনস্টলেশনের অনুমতি চাইলে নির্দেশনা অনুসরণ করুন।

✅ ধাপ ৫ — অ্যাপ ওপেন করে পারমিশন

অ্যাপের কাজ অনুযায়ী নিচের অনুমতিগুলো চাইতে পারে:

🎙️ Microphoneআপনার কথা রেকর্ড করার জন্য।
♿ Accessibility Serviceসমর্থিত অ্যাপে টাইপিং/টেক্সট ইনপুটে সহায়তার জন্য।
📲 Display over appsঅন্যান্য অ্যাপের ওপর ভাসমান মাইক্রোফোন বাটন দেখানোর জন্য।
মনে রাখুন: Accessibility ও Overlay অনুমতি শক্তিশালী। শুধু নিজের তৈরি অ্যাপকে প্রয়োজন অনুযায়ী অনুমতি দিন এবং অজানা অ্যাপকে এসব অনুমতি দেবেন না। সব অ্যাপে সরাসরি লেখা বসানো Android-এর সংস্করণ ও অ্যাপের সীমাবদ্ধতার কারণে সব সময় সম্ভব নাও হতে পারে।

🔑 ধাপ ৬ — Groq API Key সেটআপ

  1. console.groq.com এ গিয়ে অ্যাকাউন্ট তৈরি বা লগইন করুন।
  2. API Keys সেকশনে নতুন Key তৈরি করে কপি করুন।
  3. আপনার তৈরি করা অ্যাপের Settings-এ Key পেস্ট করে Save করুন—যদি অ্যাপটি এই সুবিধা সমর্থন করে।
প্রো টিপস: মডেল হিসেবে whisper-large-v3 ব্যবহার করতে পারেন; বাংলা ভয়েস শনাক্তকরণে এটি কাজে লাগতে পারে। তবে API-এর বর্তমান মডেল-সমর্থন ও সীমা Groq-এর ডকুমেন্টেশন থেকে যাচাই করুন।
API Key নিরাপত্তা: Key কাউকে পাঠাবেন না, স্ক্রিনশটে দেখাবেন না বা পাবলিক GitHub-এ রাখবেন না। শুধু ফোনের অ্যাপে Key রাখলে সেটি পুরোপুরি গোপন থাকে না; প্রকাশ্য ব্যবহারের অ্যাপের জন্য নিরাপদ ব্যাকএন্ড ব্যবহার করা ভালো।

🧾 Google Sheets-এ অনলাইন ইনভেন্টরি ও ভাউচার অ্যাপ

নিচের প্রম্পটটি ChatGPT বা Claude-এ দিলে Google Sheets ও Apps Script ব্যবহার করে দোকানের স্টক, সদস্য, জমা-বাকি এবং প্রিন্টযোগ্য ভাউচার অ্যাপ তৈরির সম্পূর্ণ কোড চাইতে পারবেন।

📝 অ্যাপ তৈরির প্রম্পট

সম্পূর্ণ প্রম্পটটি কপি করে ChatGPT বা Claude-এ পেস্ট করুন:

আমি Google Sheets এবং Google Apps Script দিয়ে একটি সম্পূর্ণ, মোবাইল ও কম্পিউটার-উপযোগী অনলাইন দোকান ইনভেন্টরি, সদস্যের হিসাব এবং ভাউচার ম্যানেজমেন্ট অ্যাপ তৈরি করতে চাই। অ্যাপটি Apps Script Web App হিসেবে চলবে এবং Google Sheet-এ তথ্য সংরক্ষণ করবে। নিচের চাহিদা অনুযায়ী সম্পূর্ণ কার্যকর কোড ও সেটআপ নির্দেশনা দাও। প্রযুক্তি ও কোড: - Google Apps Script-এর সম্পূর্ণ Code.gs এবং Index.html কোড আলাদা করে দাও; HTML ফাইলের নাম হবে Index। - Google Sheet-এ প্রয়োজনীয় শিট ও হেডার স্বয়ংক্রিয়ভাবে তৈরি করার setup ফাংশন দাও। Members, Products, Vouchers, VoucherItems এবং Payments-এর মতো প্রয়োজনীয় শিট ব্যবহার করো। - google.script.run দিয়ে নিরাপদে সার্ভার ফাংশন কল করো। ইনপুট যাচাই, ত্রুটি বার্তা, লোডিং অবস্থা এবং সফল সংরক্ষণের বার্তা দেখাও। কোনো এরর নীরবে উপেক্ষা করো না। - বাংলা ভাষার পরিষ্কার, responsive UI বানাও, যেন মোবাইল, ট্যাবলেট ও কম্পিউটার থেকে ব্যবহার করা যায়। ফিচার: - সদস্য যোগ, সম্পাদনা ও তালিকা দেখার ব্যবস্থা রাখো। - পণ্য যোগ/সম্পাদনা, একক দর এবং বর্তমান স্টক রাখো; স্টক যোগ/সমন্বয়ের ব্যবস্থা দাও। বিক্রির ভাউচার করলে স্টক কমবে এবং পর্যাপ্ত স্টক না থাকলে তা আটকে স্পষ্ট বার্তা দেখাবে। - নতুন ভাউচারে সদস্য নির্বাচন, তারিখ এবং স্বয়ংক্রিয় ভাউচার নম্বর থাকবে। ক্রমিক নম্বর, পণ্যের নাম, পরিমাণ, একক দর ও লাইনের মোট মূল্যসহ যত খুশি পণ্যের সারি যোগ/বাদ দেওয়া যাবে। - প্রতিটি লাইনের মোট = পরিমাণ × একক দর; ভাউচারের মোট, পরিশোধিত টাকা এবং বকেয়া স্বয়ংক্রিয়ভাবে হিসাব করো। বকেয়া কখনো ঋণাত্মক হবে না। আংশিক ও পরবর্তী পেমেন্ট সংরক্ষণ এবং সদস্যভিত্তিক পেমেন্টের ইতিহাস দেখাও। - ড্যাশবোর্ডে মোট সদস্য, মোট পণ্য/স্টক, সদস্যদের কাছ থেকে মোট আদায়কৃত টাকা এবং মোট বকেয়া দেখাও। জমা ও বকেয়া যেন Payments ও ভাউচারের তথ্য থেকে সঠিকভাবে গণনা হয়; একই পেমেন্ট একাধিকবার গণনা করো না। - ভাউচার সংরক্ষণ, আগের ভাউচার খোঁজা/দেখা, প্রিন্ট করার উপযোগী প্রিন্ট লেআউট এবং শেয়ার বাটন দাও। শেয়ার সুবিধা না থাকলে ভাউচারের তথ্য কপি করার বিকল্প দাও। - একই সময়ে একাধিক ব্যবহারকারীর সংরক্ষণে ভাউচার নম্বর ও স্টক যেন ভুল না হয়; প্রয়োজনে Apps Script LockService ব্যবহার করো। - সংবেদনশীল তথ্য বা পাসওয়ার্ড কোডে রেখো না। Web App-এর access Google অ্যাকাউন্ট/Deploy সেটিংস দিয়ে নিয়ন্ত্রণ করার পরামর্শ দাও। উত্তরের বিন্যাস: ১. প্রথমে Code.gs-এর সম্পূর্ণ কোড। ২. এরপর Index.html-এর সম্পূর্ণ কোড। ৩. Google Sheet তৈরি থেকে Apps Script-এ কোড বসানো, setup চালানো ও অনুমতি দেওয়া পর্যন্ত ধাপ। ৪. Deploy → New deployment → Web app-এর সঠিক সেটিংস, URL খোলা এবং Google অ্যাকাউন্ট দিয়ে প্রবেশের নির্দেশনা। ৫. কীভাবে পরীক্ষা করব এবং সাধারণ সমস্যা হলে কী করব। কোনো অংশ বাদ দিও না বা “বাকি কোড একই” লিখো না; কোডে ব্যবহৃত প্রতিটি সার্ভার ফাংশন ও UI ফাংশনের বাস্তব implementation দাও।

⚙️ Google Sheets ও Apps Script সেটআপ

২

📄 নতুন Google Sheet তৈরি করুন

  1. আপনার Google অ্যাকাউন্টে লগইন করে Google Sheets খুলুন।
  2. Blank spreadsheet নির্বাচন করে শিটের একটি নাম দিন, যেমন “দোকান ইনভেন্টরি”।
  3. এই শিটের Extensions → Apps Script নির্বাচন করুন।
৩

🧩 Code.gs ও Index.html-এ কোড বসান

  1. Apps Script-এ Code.gs খুলে আগের কোড মুছে AI-কে দেওয়া প্রম্পটের উত্তরের সম্পূর্ণ Code.gs কোড পেস্ট করুন।
  2. বাম পাশের + চাপুন → HTML নির্বাচন করুন → ফাইলের নাম Index দিন। ফাইলটি Index.html হিসেবে তৈরি হবে।
  3. Index.html-এ উত্তরের সম্পূর্ণ HTML কোড পেস্ট করুন। তারপর Save করুন।
  4. উত্তরে দেওয়া setup ফাংশনটি নির্দেশনা অনুযায়ী একবার চালান এবং Google-এর অনুমতি চাইলে পর্যালোচনা করে অনুমতি দিন।
খেয়াল রাখুন: শুধু প্রম্পট কপি করলে অ্যাপ তৈরি বা শিটে ডেটা সংরক্ষণ শুরু হবে না। AI-এর উত্তরের সম্পূর্ণ কোড Apps Script-এ বসিয়ে সেটআপ ও Deploy করতে হবে।
৪

🚀 Web App হিসেবে Deploy করুন

  1. Apps Script-এর Deploy → New deployment নির্বাচন করুন।
  2. Type হিসেবে Web app নির্বাচন করুন।
  3. Execute as এবং Who has access অপশন আপনার প্রয়োজন অনুযায়ী সেট করুন। শুধু নিজের বা নির্দিষ্ট ব্যবহারকারীদের জন্য হলে সীমিত Google অ্যাকাউন্ট অ্যাক্সেস রাখুন।
  4. Deploy চাপুন, অনুমতি সম্পন্ন করুন এবং তৈরি হওয়া Web App URL কপি করে খুলুন। পরিবর্তিত কোড প্রকাশ করতে নতুন deployment version দিতে হতে পারে।
  5. URL-টি মোবাইল, ট্যাবলেট বা কম্পিউটারে খুলে Google অ্যাকাউন্ট দিয়ে প্রবেশ করে সদস্য, পণ্য, ভাউচার, পেমেন্ট ও প্রিন্ট পরীক্ষা করুন।
নিরাপত্তা: “Anyone” অ্যাক্সেস দিলে লিংক পাওয়া অন্যরাও অ্যাপ ব্যবহার করতে পারে। ব্যক্তিগত হিসাবের জন্য অ্যাক্সেস সীমিত রাখুন এবং Google অ্যাকাউন্টের অনুমতি ছাড়া কারও সঙ্গে শিট শেয়ার করবেন না।
